### 💡 Framework Architecture Principles I Follow

- 🛡️ **Web-First Assertions**: Auto-retrying expectations over arbitrary timeouts (`page.waitForTimeout` is strictly forbidden).
- 🧩 **Robust Locator Priority**: Accessible roles (`getByRole`), labels (`getByLabel`), and test-ids (`getByTestId`) over brittle XPath/CSS selectors.
- ⚡ **CI Sharding & Speed**: Test matrix sharding across multiple runners to achieve fast feedback loops (< 5 minutes on pull requests).
- 🔄 **Isolated Test Data**: Database transactions, clean fixture setups, and teardowns to prevent flaky test interdependencies.
